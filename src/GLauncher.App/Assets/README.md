# Generated production assets

Created with the built-in image-generation tool for GLauncher on 2026-11-03. No assets or code from OHMERA/XMB are used.

- `icons.png`: original transparent 4×4 icon atlas. In reading order: Play, Recommended, Library, Settings; Add, Edit, Back, Search; Save, Folder, Video, Profile; Close, More, Moon, Controller. Runtime clipping preserves the source image.
- `energy-clouds.png`: original purple/cyan cartoon energy-cloud background, no text or third-party game imagery.
- `opening.mp4`: silent three-second H.264 animation of that background, made with FFmpeg zoom/fade. The app draws live GLauncher typography above it. No sound was generated.

Design prompts asked for a cohesive glossy lilac/cyan cartoon icon family with generous transparent cell margins, and wide soft energy clouds with a dark low-detail centre. These are original assets rather than claims of game ownership or live provider content.
