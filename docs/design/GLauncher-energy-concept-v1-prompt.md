## Prompt

Use case: ui-mockup.
Create ONE high-fidelity visual concept sheet for a Windows game launcher named exactly "GLauncher". This is a fresh design based only on this brief. The image should show an understanding of the product's flow, not finalize its design. Landscape 4K composition, approximately 3840 x 2400, with FOUR large, readable, front-facing app screens arranged in a clean 2 x 2 grid, narrow gutters and simple captions. No monitor, laptop, desk, perspective or photographic presentation. Give all four screens the same coherent design language and navigation.

ART DIRECTION: default dark mode, very polished and playfully cartoonish. Deep midnight surfaces, soft sculpted rounded panels, beautifully rounded readable type, jewel-colored illustrated game art, subtle tactile depth. Expressive motion suggested through soft volumetric ENERGY CLOUDS and gently undulating luminous waves around game covers. These are pillowy colored vapor and fluid ripples, not rigid neon rectangles or electrical lightning. There should be enough calm dark space to appreciate the effects. The app feels lively, friendly and responsive, with a refined animated identity. Avoid the previous generic cinematic/store dashboard look and any console-menu replica.

PANEL 1 — caption "01  Opening video".
A frame from GLauncher's brief opening video: the exact centered wordmark "GLauncher" emerging elegantly from one flowing, cartoon-like ribbon of luminous cloud on a dark background. Make it feel like a polished animation still using the same cloud language as the interface. Only the app name inside this screen; no invented slogan, video controls or soundtrack imagery. A simple small arrow in the gutter suggests it transitions into Recommended.

PANEL 2 — caption "02  Recommended".
The actual app home after the intro. Compact wordmark, navigation "Recommended", "Library", "Settings", with Recommended active. Heading "Recommended for you". Two subpage tabs directly beneath: "Your games" (active) and "Discover". The selected page recommends games the user ALREADY OWNS: one attractive main recommendation and three smaller personal game recommendations, all with a "Play" action and subtle "Owned" labels. Use bright illustrated recognizable cover art, not store advertisements. A discreet small editorial callout OUTSIDE the app screen, next to the Discover tab, reads "Discover → Buy or download free games", to indicate the separate recommendation subpage without pretending both tabs are open simultaneously.

PANEL 3 — caption "03  Library · hover state".
This is the key showcase. Same top navigation with Library active, a Search field and unobtrusive platform filters. A beautifully spaced 4 + 3 grid of seven portrait game covers, each on a custom sculpted card back shaped or patterned for its platform. Show all seven platform categories legibly, one on each card: "PS2", "PS3", "Xbox 360", "Xbox Series S/X", "PC", "Mobile", "Other". Illustrative game examples: Jak and Daxter, LittleBigPlanet, Sonic Unleashed, Forza Horizon 5, Hades II, Monument Valley, and a custom game. Use distinct provisional aura hues: indigo, crimson, spring green, emerald, cyan, pink, amber respectively. MOST CARDS REST QUIETLY with restrained cloud edges. One card, Hades II on PC, is clearly HOVERED: gently lifted and slightly enlarged, with an especially beautiful soft cyan energy cloud curling around its cover, layered pulsing wave contours shifting from deep teal to pale turquoise, and a neat revealed nameplate reading "Hades II" and "PC". A small cursor is over this card. Communicate the hover motion using graceful flowing cloud shapes and tiny curved motion traces, not duplicate ghost cards. Covers must stay readable and unclipped. Platform identity lives in BOTH the card back and the aura.

PANEL 4 — caption "04  Full game page".
An entire dedicated Hades II game page, with matching navigation, a simple Back action, large game cover, atmospheric matching background illustration, title "Hades II", platform badge "PC", a short readable game description and prominent "Play" button. Place a visible three-dot "..." edit-information menu near the game title. This is a full page, not a modal. Show a very small open menu from the three-dot button with "Edit information", "Change cover", "Change platform", making customization clear without dominating the page.
