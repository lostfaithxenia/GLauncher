# Shared GLauncher instructions

## Read before work

- Follow the owner's latest explicit instructions.
- Read docs/PRODUCT_BRIEF.md, docs/STATUS.md, docs/DECISIONS.md and docs/COLLABORATION.md.
- Inspect current issues/PRs and verify the actual repository remote, base branch and head.
- The handoff kit does not establish that a repository, app, build or integration exists.

## Product direction

- Start fresh as GLauncher; SYN is the owner's online name.
- Do not inherit OHMERA/XMB architecture, branding, assets or feature scope.
- Use the energy-cloud concept as a provisional visual reference; newer written requirements take precedence.
- Covers are 9:16. Prominent profile pictures, platform cloud effects and responsive motion matter.
- Generate app-owned icons as a coherent image-asset family.
- Do not create sound effects; the owner will supply them.
- Additional themes and alternate UI designs follow the first alpha.

## Shared work

- Follow the issue ownership and branch conventions in docs/COLLABORATION.md.
- Work in separate checkouts/worktrees. Do not overwrite another assistant's work.
- Give shared files/contracts one active owner and coordinate dependencies first.
- Do not treat assistant names as real GitHub usernames or fabricate independent approvals.
- Follow actual repository review/merge rules and existing owner authorization.
- Choose routine reversible details autonomously. Ask only for genuinely missing information or consequential access/cost/product choices.

## Evidence

- Use real implementations and real data sources for claimed features.
- Distinguish fixture/demo data from user data and live integrations.
- Report actual commands, results, screenshots and limitations.
- Windows builds and hardware/game tests must be reported separately.
- No universal game-speed, achievement, controller or overlay claims without evidence.
- Keep credentials, local profile data, personal game libraries and build caches out of Git.
- Preserve user data and other repositories.
- Record completed work, exact commit/PR and next handoff in GitHub.
